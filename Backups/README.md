# Backups — Arsip Iterasi Desain

Folder ini **bukan aplikasi yang di-deploy**, melainkan arsip eksplorasi desain untuk landing page portofolio pribadi (Jihad Prakoso). Isinya versi-versi alternatif dari halaman utama yang dipertahankan sebagai jejak proses desain.

## Isi

| File | Deskripsi |
|---|---|
| `index copy.html` | Versi awal landing page portofolio (full) — "Jihad - Full Stack Web Developer", lengkap dengan animasi Typed.js |
| `index_systech.html` | Iterasi tema "SysTech Engineering" — cikal bakal `../index.html` yang aktif sekarang |
| `index_minimalist.html` | Varian gaya minimalis |
| `index_neobrutalism.html` | Varian gaya neo-brutalism (border tebal, warna kontras) |
| `index_organic.html` | Varian gaya organic (bentuk lembut, palet hangat) |
| `profile.jpg` | Aset foto profil untuk varian desain (tidak dipakai halaman aktif) |

## Halaman yang Aktif

Landing page portofolio yang dipakai saat ini ada di root My_Porto:

```
http://localhost/My_Porto/index.html
```

(judul: *Jihad | SysTech Engineering*, memakai aset `profile_jihad.png`)

## Catatan

- Semua file di sini berdiri sendiri (self-contained HTML + CDN) dan bisa dibuka langsung di browser untuk perbandingan desain.
- Berkas di folder ini ikut dilindungi `.htaccess` root: directory listing dimatikan, sedangkan file `.html` tetap dapat dibuka.
- Halaman-halaman ini tidak ditautkan dari halaman utama mana pun — murni arsip.
